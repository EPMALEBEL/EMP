Install EPM on your device

Engineering Project Manager works as an app on phones, tablets and computers. It always opens this server, so everyone sees the same live data.

One-tap install

Your browser can install it directly.

Install app

Android (Chrome)

  1. Open this address in Chrome.
  2. Tap the ⋮ menu.
  3. Tap Install app or Add to Home screen.
  4. Open EPM from the home screen.

iPhone and iPad (Safari)

  1. Open this address in Safari (not Chrome).
  2. Tap the Share button (square with arrow).
  3. Tap Add to Home Screen, then Add.
  4. Open EPM from the home screen.

Windows and Mac (Chrome or Edge)

  1. Open the address.
  2. Chrome: menu ⋮ → Cast, save and share → Install page as app (tick “Open as window”).
    Edge: menu … → Apps → Install this site as an app.
  3. EPM now has its own window, taskbar icon and Start-menu entry.

Selfie camera

The camera needs the secure address (https://…:3001). Install from that address if you use Attendance on this device, and accept the browser warning once.

The app needs the office server to be running and your device to be on the same Wi-Fi or network.
